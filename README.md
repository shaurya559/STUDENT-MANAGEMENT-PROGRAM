# Student Grade Management System

A C++ based **Student Grade Management System** developed as an individual OOPS mini project.

This project helps manage student records, enter subject marks, calculate total marks, percentage and grades, and generate student report cards.

## About the Project

The Student Grade Management System is a console-based application developed using C++. It makes student result management easier and more organised.

The project demonstrates the use of Object-Oriented Programming (OOPS) concepts and basic C++ programming.

## Features

- Add new student records.
- Enter student name and roll number.
- Store marks of five subjects.
- Calculate total marks.
- Calculate percentage and grade.
- Display individual student report cards.
- View and edit student records.
- Save and load student records using file handling.

## Technologies Used

- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOPS)
- **File Handling:** C++ file streams
- **Application Type:** Console-Based Application

## OOPS Concepts

The project focuses on the following concepts:

- **Class and Object:** Used to organise student data and related functions.
- **Encapsulation:** Used to combine data and functions inside a class.
- **Abstraction:** Used to simplify the interaction with the system.
- **File Handling:** Used to store and retrieve student records.

*Inheritance and polymorphism should be included here only if they are implemented in the final source code.*

## Grade Calculation

The system calculates the total marks and percentage based on five subjects, each having a maximum of 100 marks.

| Percentage | Grade |
|---|---|
| 90% and above | A |
| 80% – 89% | B |
| 70% – 79% | C |
| 60% – 69% | D |
| Below 60% | F |

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Compile the C++ source file:

   ```bash
   g++ main.cpp -o student_grade
   ```

4. Run the program:

   **Windows:**
   ```bash
   student_grade.exe
   ```

   **Linux/macOS:**
   ```bash
   ./student_grade
   ```
